Acesso do administrador

Os dados operacionais são sincronizados com o Cloud Firestore e também mantêm uma cópia local de contingência. As senhas dos usuários são armazenadas como hash; ainda assim, para exposição pública em larga escala, recomenda-se evoluir o login para Firebase Authentication com regras por perfil.

Usuários e permissões

Perfil Vendedor: ao entrar, o usuário verá somente Cozinha / Comandas e Vendas / PDV. Dashboard, estoque, relatórios, caixa, configurações e suporte ficam bloqueados.
